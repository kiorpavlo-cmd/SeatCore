# Mio!

Русский интерфейс управления рестораном с отдельной серверной частью.

## Открыть сайт

На этом Mac откройте двойным щелчком **Запустить Mio!.command** в папке Mio!. Оставьте окно запуска открытым: оно поддерживает работу сервера. Сайт откроется по адресу http://127.0.0.1:4175. Если сервер уже работает, просто откройте этот адрес. Исходный index.html напрямую открывать не нужно.

Требуется Node.js 24 или новее. Файл запуска также умеет использовать установленный runtime Codex на этом компьютере. Готовая сборка находится в web/dist.

На новом компьютере выполните из папки Mio!:

```sh
npm run setup
npm start
```

## Демо на GitHub Pages

Для репозитория настроена публикация браузерной демо-версии по адресу
`https://kiorpavlo-cmd.github.io/SeatCore/`. В демо данные остаются в хранилище
текущего браузера; они не синхронизируются с рестораном, а форма бронирования
не отправляет заявки. В демо используются обезличенные брони и схема зала,
приближенная к локальной версии. Для реального приёма бронирований нужен
публичный сервер с постоянным хранилищем и отдельной конфигурацией безопасности.

## Папки

- `web/` — страницы, компоненты, маршруты, формы и стили браузерного интерфейса.
- `server/` — HTTP API, серверные проверки, SQLite, журнал действий и резервное копирование.
- `server/contracts/` — чистые правила и форматы, используемые сервером и клиентом; сервер проверяет запросы независимо от браузера.
- `server/data/` — рабочая база, создаётся при запуске; не включается в исходники и архив доставки.

## Разработка и проверка

```sh
npm test             # серверные тесты, проверка клиента и сборка
npm run build        # пересобрать сайт после изменений
npm run backup       # создать согласованную копию SQLite
npm run dev          # сервер с автоматическим перезапуском
```

Для разработки интерфейса оставьте сервер запущенным и во втором терминале выполните `npm --prefix web run dev`. Vite перенаправляет `/api` на локальный сервер. База одна для обоих адресов; личные фильтры и выбранная дата остаются в соответствующем браузере.

Mio работает локально по адресу http://127.0.0.1:4175. Рабочая база хранится в `server/data/mio.sqlite`, резервные копии — в `server/data/backups/`. Интернет для чтения и сохранения данных ресторана не требуется. При недоступности локального сервера сохранение приостанавливается; приложение не переключается на другое хранилище. Параметры интернет-запуска не используются. Подробнее: [сервер](server/README.md), [клиент](web/README.md).
